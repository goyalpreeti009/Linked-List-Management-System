# Linked List Management System

Author
Name: [Preeti Goyal]

Project Level: 2nd Year College Level DSA Mini Project

## Objective
Data Structures and Algorithms (DSA) mini-project designed to implement and practice Singly and Doubly Linked Lists through a menu-driven console application.

## Language Used
* C++ 

## Features
* **Singly Linked List:** Comprehensive implementation with 19 distinct operations including insertions, deletions, searching, reversing, sorting (Bubble/Merge Sort), and duplicate removal.
* **Doubly Linked List:** Full bidirectional implementation supporting forward and backward traversal alongside standard manipulation operations.
* **Robust Edge Case Handling:** Manages empty lists, single-node lists, invalid position lookups, and duplicate data safely.

## Operations Supported

### Singly Linked List Menu
1. Insert at Beginning / End / Position / After Node / Before Node
2. Delete from Beginning / End / Position / By Value[cite: 1]
3. Search, Update, and Display[cite: 1]
4. Count Nodes, Find Maximum, Find Minimum, and Find Middle Element[cite: 1]
5. Reverse, Sort, and Remove Duplicates[cite: 1]

### Doubly Linked List Menu
1. Insert at Beginning / End / Position / After Node / Before Node[cite: 1]
2. Delete from Beginning / End / Position / By Value[cite: 1]
3. Search, Update, Display Forward, and Display Backward[cite: 1]
4. Count Nodes, Find Maximum, Find Minimum, and Find Middle Element[cite: 1]
5. Reverse, Sort, and Remove Duplicates[cite: 1]
